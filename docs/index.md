# Notes PARA

A follow-along way to run [PARA](https://fortelabs.com/blog/para/) as a second brain in the iPhone or iPad Notes app.

You already have the app. This guide is the setup and the habits: which folders to create, how a new note lands in the built-in **Notes** folder, and how you empty that inbox so active work stays findable. It is written so you can set it up in an afternoon and still recognise it in a month.

This is an opinionated implementation for Notes on **iOS 27** or **iPadOS 27**. It leaves the Mac and web apps aside where they behave differently.

Tiago Forte’s PARA method and Building a Second Brain are the foundation. This repository is an independent guide, not an Apple or Forte Labs product.

Next actions do not live here. If you want Getting Things Done in Reminders, use the sibling guide [Reminders GTD](https://markheydon.me.uk/ios-reminders-gtd/).

## The short version

Capture into the built-in **Notes** folder. Treat it as Inbox. File each note by how soon you will *use* it, not by topic.

Four folders are enough:

| Folder | What belongs there |
| --- | --- |
| Projects | Work with a finish line |
| Areas | Ongoing standards with no end date |
| Resources | Topics you may need later |
| Archives | Anything from the other three that is no longer active |

One note per project is the default. A subfolder is only worth it when that project or area has several notes.

## What you need

- An iPhone on iOS 27 or an iPad on iPadOS 27, signed into iCloud with Notes turned on. Use the **iCloud** account in Notes, not an IMAP mailbox. Apple Intelligence extras, such as summarising a long note, need a supported device (for example iPhone 15 Pro or later, or an iPad with Apple Intelligence). The folders themselves do not.
- About an hour the first time, then a short weekly review
- No extra apps
